# Cheshire — маска для Hotline Miami

Исходники GML-мода для маски `mask_cheshire`. Добавлены протокол подмены, маскировка, фазовый рывок, проверка урона и точки подключения к AI врагов.

> Большой `data.win` не нужен в репозитории и намеренно исключён из Git. Здесь лежит исходный код и инструкция по интеграции, а не уже пропатченный `data.win`: без игрового файла нельзя надёжно встроить скрипты в конкретную сборку и проверить её на запуск.

См. [инструкцию на русском](mod_cheshire/INTEGRATION_RU.md).
